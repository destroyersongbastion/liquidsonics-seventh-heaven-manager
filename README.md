## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Seventh Heaven presets by room type and character |
| **Mix Notes** | Document send level and wet/dry ratio settings per preset |
| **Genre Curation** | Tag and curate reverb presets per music genre and production style |
| **Room Reference** | Log real room emulation references for each Seventh Heaven preset |
